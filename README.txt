МОЁ РАСПИСАНИЕ — версия 1

В приложении уже заполнено расписание из предоставленного DOCX на понедельник–пятницу.
Можно добавлять, редактировать и удалять занятия (редактирование доступно по значку карандаша; для удаления можно очистить запись? Для удаления см. ниже).
Изменения автоматически сохраняются в локальном хранилище браузера на этом устройстве.
Экспорт/импорт сохраняет резервную копию в JSON. Кнопка ↺ возвращает исходное расписание.

ВАЖНО:
Это первая рабочая веб-версия, которую можно открыть в браузере Android. Это ещё не APK-файл.
Чтобы установить как приложение: разместите папку на HTTPS-хостинге, откройте ссылку в Chrome Android и выберите меню ⋮ → «Установить приложение» или «Добавить на главный экран».
Не очищайте данные браузера без экспорта резервной копии.

Примечание к исходному расписанию:
Некоторые строки содержат только имена без класса/предмета. Они сохранены как записи, без догадок. В частности: Найденко, Бендус, Алексей, Вероника, Платон, Карина, Артём, Давид, Михаил, Рома, Юля и Даша.
